Security Awareness Assessment Methodology

Academic framework for evaluating staff cybersecurity awareness and calculating organizational risk

End-to-End Assessment Pipeline
1. Question Bank → 2. Randomized Quiz → 3. Staff Answers → 4. Server-Side Scoring → 5. Category Analysis → 6. Awareness Classification → 7. Remediation & Report
1. Server-Side Scoring Enforcement

To prevent client-side tampering, JavaScript is restricted to UI interactions, countdown timers, and progress bars. Answer keys are retained exclusively on the server where scoring.py evaluates accuracy against database records.

2. Category Weakness Mapping

Questions are categorized across 12 domains (Password Security, Phishing, Social Engineering, MFA, Ransomware, Safe Browsing, etc.). Performance is aggregated per category to identify targeted organizational vulnerabilities.

3. Risk Classification Tiers
  • 90 – 100%: Excellent (*Low Awareness Risk*)
  • 80 – 89%: Very Good (*Moderate-Low Risk*)
  • 70 – 79%: Good (*Acceptable Threshold*)
  • 60 – 69%: Needs Improvement (*Elevated Awareness Risk*)
  • Below 60%: High Awareness Risk (*Critical Risk*)
4. Automated Reporting

Every completed attempt triggers ReportLab PDF certificate compilation into protected non-public storage (instance/uploads/reports/) alongside CSV export functionality for security trainers.
